# Shulker Drops Two Shells

This is a simple datapack for Minecraft version 26.3. It changes the loot table of shulker drops so shulkers always drop exactly 2 shells, meaning you get one shulkerbox per shulker.

The loot table is not affected by Looting or checks if the shulker was killed by a player.

As far as I tested it works in both singleplayer and servers (fabric).
